# Security policy

Do not open public issues containing API keys, tokens, private project paths, raw
research data, or unpublished results. Report a suspected secret leak or unsafe
installer behavior privately to the repository maintainer.

Before sharing logs, redact `DEEPSEEK_API_KEY`, credentials, dataset locations, and
participant or site identifiers. This project is beta software; review installer
dry-run output and worker diffs before applying them.
